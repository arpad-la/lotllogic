Pipのラグーンのヘルプです。答えが見つからないときは、arpadlarrinaga@gmail.com にメールするか、X で @soyarpad にメッセージを送ってください。折り返しご連絡します。

遊び方は？

色のついた池ごとに1匹、各行に1匹、各列に1匹ずつウーパールーパーを置きます。ウーパールーパー同士は、斜めも含めて隣り合いません。マークでウーパールーパーが入れない場所に小石を置き、置くでウーパールーパーを置きましょう。ルールは各レベルの?ボタンや、コレクションタブの図鑑でも確認できます。

置くのに2回タップが必要なのはなぜ？

1回目のタップでウーパールーパーが入る場所を表示し、2回目で置きます。うっかりタップしてエラを失うことがないようにするためです。設定 → ウーパールーパーを置く操作 で「1回タップ」に切り替えられます。

ヒントと潮さらいの仕組みは？

ヒントは次の論理的な一手をハイライトし、その理由を説明します。潮さらいは、すでに候補から外れたすべての場所に小石を置きます。どちらも最初に3つずつあり、プレイした日ごとに1つずつ増えます。

「広告を削除」を購入しました。別のデバイスでも使うには？

同じ Apple アカウントでサインインし、ゲームの設定を開いて購入を復元をタップしてください。購入はお使いのすべてのデバイスで有効です。

広告のプライバシー設定を変更するには？

欧州経済領域、英国、スイスでは、設定 → 広告のプライバシー設定 を開いてください。どの地域でも、iOS の 設定 → プライバシーとセキュリティ → トラッキング で、すべてのアプリのトラッキングをオフにできます。

デイリーリマインダーを止めるには？

ゲーム内の 設定 → デイリーリマインダー をオフにするか、iOS の設定で Axodokutl の通知をオフにしてください。リマインダーは、ゲームを開いていない日にだけ届きます。

進行状況が消えてしまった

進行状況はデバイスに保存されています。アプリを削除すると消え、設定 → 進行状況をリセット を使うと意図的に消去されます。リーダーボードのスコアとアチーブメントは Game Center に残ります。

Game Center が表示されない

iOS の 設定 → Game Center でサインインしてから、ゲームを開き直してください。サインインすると、ゲームの設定に Game Center の項目が表示されます。
