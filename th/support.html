ฝ่ายช่วยเหลือ Axodokutl

ความช่วยเหลือสำหรับลากูนของ Pip หาคำตอบไม่เจอใช่ไหม ส่งอีเมลมาที่ arpadlarrinaga@gmail.com หรือส่งข้อความหา @soyarpad บน X แล้วเราจะติดต่อกลับ

เล่นอย่างไร

วางแอกโซลอเติลหนึ่งตัวในทุกบ่อสี หนึ่งตัวในทุกแถว และหนึ่งตัวในทุกคอลัมน์ แอกโซลอเติลจะไม่แตะกันเลย แม้แต่ในแนวทแยง ใช้ มาร์ก เพื่อวางกรวดบนจุดที่มีแอกโซลอเติลไม่ได้ แล้วใช้ วาง เพื่อวางแอกโซลอเติลลงไป ดูกติกาได้จากปุ่ม ? ในทุกด่าน และในคู่มือภาคสนามที่แท็บสะสมด้วย

ทำไมการวางต้องแตะสองครั้ง

การแตะครั้งแรกจะแสดงว่าแอกโซลอเติลจะไปอยู่ตรงไหน และการแตะครั้งที่สองจะวางลงไป การแตะพลาดจึงไม่ทำให้คุณเสียเหงือก คุณสามารถเปลี่ยนเป็นแตะครั้งเดียวได้ที่ การตั้งค่า → วางแอกโซลอเติลด้วย

คำใบ้และคลื่นกวาดทำงานอย่างไร

คำใบ้จะไฮไลต์ขั้นตอนเชิงตรรกะถัดไปและอธิบายว่าทำไมจึงได้ผล คลื่นกวาดจะวางกรวดบนทุกจุดที่ถูกตัดออกไปแล้ว คุณจะเริ่มต้นด้วยอย่างละ 3 และได้เพิ่มอีกอย่างละ 1 ทุกวันที่คุณเล่น

ฉันซื้อ “ลบโฆษณา” แล้ว จะใช้บนอุปกรณ์อื่นได้อย่างไร

ลงชื่อเข้าด้วย Apple ID เดียวกัน เปิดการตั้งค่าในเกม แล้วแตะ กู้คืนการซื้อ การซื้อนี้ใช้ได้กับทุกอุปกรณ์ของคุณ

จะเปลี่ยนตัวเลือกความเป็นส่วนตัวของโฆษณาได้อย่างไร

ในเขตเศรษฐกิจยุโรป สหราชอาณาจักร และสวิตเซอร์แลนด์ ให้เปิด การตั้งค่า → ตัวเลือกความเป็นส่วนตัวของโฆษณา และไม่ว่าคุณจะอยู่ที่ไหน คุณสามารถปิดการติดตามสำหรับทุกแอปได้ที่ การตั้งค่า iOS → ความเป็นส่วนตัวและความปลอดภัย → การติดตาม

จะหยุดการเตือนรายวันได้อย่างไร

ปิด การตั้งค่า → การเตือนรายวัน ในเกม หรือปิดการแจ้งเตือนของ Axodokutl ในการตั้งค่า iOS การเตือนจะมาเฉพาะในวันที่คุณยังไม่ได้เปิดเกมเท่านั้น

ความคืบหน้าของฉันหายไป

ความคืบหน้าจะถูกบันทึกไว้ในอุปกรณ์ของคุณ การลบแอปจะลบความคืบหน้าไปด้วย และ การตั้งค่า → รีเซ็ตความคืบหน้า จะลบความคืบหน้าโดยตั้งใจ ส่วน Game Center จะเก็บคะแนนบนกระดานผู้นำและความสำเร็จของคุณไว้

Game Center ไม่แสดง

ลงชื่อเข้า Game Center ที่ การตั้งค่า iOS → Game Center แล้วเปิดเกมใหม่ แถว Game Center จะปรากฏในการตั้งค่าเมื่อคุณลงชื่อเข้าแล้ว
